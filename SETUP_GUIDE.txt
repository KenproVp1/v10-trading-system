Terminal 1 (API):

  python -m streamlit run dashboard.py

=== TROUBLESHOOTING ===

Problem: "Cannot connect to API from dashboard"
Solution: Make sure API is running in Terminal 1 first

Problem: "Port already in use"
Solution: Change port in command:
  python -m uvicorn api:app --port 8001

Problem: Module not found (ImportError)
Solution: Reinstall requirements:
  pip install --upgrade fastapi uvicorn streamlit pandas scikit-learn requests
